# 질의회신·판례 정리 도우미 (case-law-organizer)

설계변경 관련 **질의회신과 판례 자료를 읽고, 건마다 한 줄로 정리한 표를 만들어 주는 Claude Code 스킬**입니다.

자료를 찾아 여러 사이트를 오가며 복사·붙여넣기하던 손작업을 줄이고,
사람은 만들어진 정리표를 **확인하는 일**에 집중하는 것을 목표로 합니다.

---

## 이런 분께 도움이 됩니다

- 설계변경 질의회신이나 판례를 모아 우리 건과 비교해야 하는 실무자
- 자료마다 출처·쟁점·결론을 같은 형식으로 정리해 두고 싶은 분
- AI가 정리한 내용 중 **원문에 있는 것과 없는 것**을 구분해서 보고 싶은 분

## 무엇을 만들어 주나요

`raw/` 폴더에 넣은 자료를 읽고 `out/질의회신_판례_정리표.md` 파일 하나를 만듭니다.
자료 한 건이 표의 한 줄이 되고, 칸은 다섯 개입니다.

| 출처 | 사실관계 요약 | 쟁점과 결론 | 우리 건과 같은 점·다른 점 | 원문 핵심 문장 |
|---|---|---|---|---|
| 기관, 날짜, 사건번호나 회신 번호, 제목 | 어떤 설계변경이었는지 | 무엇이 쟁점이었고 어떻게 판단했는지 | 우리 건 사실관계와 견준 결과 | 결론이 드러난 문장을 원문 그대로 |

표 아래에는 두 가지 목록이 붙습니다.

- **〔원문에 없음〕 항목** — 원문에서 찾지 못해 비워 둔 칸이 어디인지
- **읽지 못한 파일** — 열지 못한 파일 이름과 그 이유

## 이렇게 동작합니다

1. `raw/`의 파일을 **우리 건 사실관계**와 **질의회신·판례 자료**로 나눕니다.
   - 파일 이름이 `우리건`으로 시작하거나 `raw/우리건/` 폴더 안에 있으면 우리 건 자료로 봅니다.
   - 어느 쪽인지 알 수 없는 파일이 있으면 정리를 시작하기 전에 먼저 물어봅니다.
2. 각 파일의 글을 읽습니다.
3. 자료마다 다섯 칸을 원문에서 뽑아 한 줄로 정리합니다.
4. 원문에 없는 내용은 **추측해서 채우지 않고** 〔원문에 없음〕이라고 적습니다.
5. 결과를 `out/`에 저장합니다. 같은 이름의 파일이 있으면 덮어쓰기 전에 확인합니다.

## 사용 방법

### 준비물

- [Claude Code](https://claude.com/claude-code)
- 정리할 질의회신·판례 자료와 우리 건 사실관계 자료

### 순서

1. 이 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/daniel898865-alt/case-law-organizer.git
   ```
2. 저장소 폴더 안에 `raw/` 폴더를 만들고 자료를 넣습니다.
   ```
   case-law-organizer/
   ├── raw/
   │   ├── 우리건_사실관계.txt      ← 우리 건 자료 (이름을 '우리건'으로 시작)
   │   ├── 질의회신_○○○.md
   │   └── 판례_○○○.pdf
   └── ...
   ```
3. 저장소 폴더에서 Claude Code를 열고 이렇게 요청합니다.
   > 질의회신 판례 정리해줘
4. 만들어진 `out/질의회신_판례_정리표.md`를 열어 확인합니다.

### 넣을 수 있는 파일 형식

| 형식 | 비고 |
|---|---|
| `.txt`, `.md` | 자료 한 건을 파일 하나로 |
| `.pdf` | 글자를 마우스로 선택할 수 있는 PDF만. 스캔본은 읽지 못합니다 |
| `.docx`, `.hwpx` | |
| `.hwp` | 환경에 따라 읽지 못할 수 있습니다. 그럴 땐 `.hwpx`, `.docx`, PDF로 저장해 다시 넣어 주세요 |

## 하지 않는 일

이 스킬은 아래 일을 **하지 않도록** 만들어져 있습니다.

- `raw/`의 원본 파일 수정·이동·삭제
- 인터넷 검색이나 사이트 자동 조회 (자료 찾기는 사람이 직접 합니다)
- 자료를 외부로 보내는 일
- 원문에 없는 내용을 추측해서 적는 일
- 법적 의견이나 판단을 덧붙이는 일

## 꼭 알아 두세요

- **정리표는 검토용 초안입니다.** 법률 자문이나 최종 판단을 대신하지 않습니다.
  인용 문장과 결론은 반드시 원문과 대조해 확인해 주세요.
- **내부 자료를 올리지 마세요.** `.gitignore`에 `raw/`와 정리표가 등록되어 있어
  Git 기록과 GitHub 업로드에서 자동으로 빠집니다. 이 설정을 지우지 마세요.
- 아직 다음 기능은 없습니다: 사이트 자동 검색, 스캔본 글자 인식,
  보고서·회신문 작성, 엑셀·워드 형식 출력.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `.claude/skills/질의회신-판례-정리/SKILL.md` | 스킬 본체 — 처리 순서와 정리표 형식 |
| `CLAUDE.md` | Claude가 이 폴더에서 지키는 작업 규칙 |
| `.gitignore` | 원본 자료·정리표·비밀정보가 업로드되지 않게 막는 설정 |
| `기록.md` | 작업 진행 기록 |
| `raw/`, `out/` | 직접 만드는 폴더 (저장소에는 포함되지 않음) |
